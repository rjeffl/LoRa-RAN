**ReadMe File for LRAN Docs Directory**

This directory contains system-level, shared, and node-specific documents for the LaRa-RAN project.
The project system PRD lives at this level in addition to an archive of initial research.

- Archive - contains various docs that have been either deprecated or supersceded
- Shared - contains documentation for shared elements amongst all nodes in the system.
- Bridge - contains documentation related to the Bridge Node.
- Gatelink - contains documentation related to the GateLink Node.
- Welllink - contains documentation related to the WellLink Node.
